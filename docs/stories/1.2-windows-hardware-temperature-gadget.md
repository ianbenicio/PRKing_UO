# Story 1.2 — Gadget de temperatura para Windows 10

Status: Done  
Epic: E15 Accessibility, Performance & Release  
Owner: `@dev`

## Story

Como usuário de Windows 10,  
quero ver as temperaturas de CPU e GPU em um pequeno overlay,  
para acompanhar o hardware sem interromper o que estou fazendo.

## Acceptance criteria

1. O gadget executa em Windows 10 x64 como uma janela compacta, transparente, sem borda e arrastável.
2. A janela permanece acima das demais por padrão e permite alternar esse comportamento pelo menu de contexto.
3. Temperaturas de CPU e GPU são atualizadas a cada segundo por meio do LibreHardwareMonitor.
4. O sensor de pacote da CPU e o sensor de núcleo da GPU têm precedência; fallbacks determinísticos cobrem nomes diferentes entre fabricantes.
5. Sensor ausente é exibido como indisponível, sem encerrar o aplicativo.
6. A posição da janela e a opção "sempre no topo" persistem entre execuções.
7. O aplicativo informa quando privilégios administrativos são necessários para acessar sensores.
8. Testes unitários cobrem seleção, fallback e classificação de temperatura.
9. Build, testes e publish Windows x64 autocontido passam sem warnings novos.

## Test scenarios

- CPU Package tem precedência sobre núcleos individuais.
- Tctl/Tdie é aceito quando CPU Package não existe.
- Média dos cores é usada como fallback.
- GPU Core tem precedência sobre Hot Spot e memória.
- Valores nulos, NaN e fora da faixa física são ignorados.
- Faixas normal, quente e crítica mudam o estado visual.
- Ausência de sensores mantém o aplicativo responsivo.

## Out of scope

- gráficos históricos;
- controle de ventoinhas, tensão ou clock;
- suporte a Windows 7/8, Linux ou macOS;
- instalador MSI e atualização automática.
